## Русский (основной)

**Название:** Malkh
**Подзаголовок (30):** Конвертер и редактор файлов
**Ключевые слова (100):** конвертер,heic,jpg,png,pdf,webp,mp4,mp3,сжать,обрезать,видео,фото,метаданные,коллаж,qr

**Описание:**
Malkh — быстрый и простой способ конвертировать и редактировать файлы прямо на Mac.

Перетаскивайте файл в Finder и нажмите клавишу — появится колесо действий:
• Shift — конвертация: HEIC, JPG, PNG, WEBP, AVIF, TIFF, PDF, MP4, MOV, MP3, M4A, FLAC, WAV и другие форматы
• Command — инструменты: обрезка, сжатие, изменение размера, пометки, рамки, фон, коллаж, скрытие данных
• Control — действия: копировать, переместить, AirDrop, плавающая полка

Также:
• Обрезка и склейка видео и аудио, кадры из видео, изменение скорости
• Нормализация громкости и аудиовизуализация
• Объединение, разделение и упорядочивание PDF
• Чтение QR-кодов из изображений и PDF
• Просмотр и удаление метаданных

Конфиденциальность прежде всего: все файлы обрабатываются только на вашем Mac. Без аккаунтов, без аналитики, без интернета. Оригиналы всегда остаются нетронутыми — Malkh сохраняет новые копии.

Языки: русский, турецкий, английский.

## English

**Subtitle:** File converter & editor
**Keywords:** converter,heic,jpg,png,pdf,webp,mp4,mp3,compress,crop,video,photo,metadata,collage,qr

**Description:**
Malkh is the fast, simple way to convert and edit files right on your Mac.

Drag a file in Finder and tap a key to open the action wheel:
• Shift — convert: HEIC, JPG, PNG, WEBP, AVIF, TIFF, PDF, MP4, MOV, MP3, M4A, FLAC, WAV and more
• Command — tools: crop, compress, resize, annotate, frame, background, collage, redact
• Control — actions: copy, move, AirDrop, floating shelf

Plus trimming and joining video and audio, video snapshots, speed changes, loudness normalization, merging/splitting/organizing PDFs, reading QR codes, and viewing or removing metadata.

Privacy first: every file is processed on your Mac. No accounts, no analytics, no internet. Your originals are never changed — Malkh saves fresh copies.

## App Review notları (İngilizce yaz)

Malkh converts and edits files locally. Usage: drag any image, video or PDF in Finder and, while dragging, press Shift (convert), Command (tools) or Control (actions); a wheel appears under the pointer — drop onto an option. Files can also be chosen with "Choose Files" in the main window. On first save, Malkh asks the user to allow a folder (NSOpenPanel) so it can write new copies next to the originals; this is stored as a security-scoped bookmark. The bundled FFmpeg/FFprobe helpers are built from source under the LGPL 2.1 (no GPL components) and run inside the app sandbox. The app does not use the network.
